# Домашняя работа 4

## Условие задачи

Вычислите вещественное значение 1 + 1/2 + 1/3 + ... + 1/N для целого N, заданного пользователем.

## 1. Алгоритм и блок-схемы

### Алгоритм:

1. Начало.
2. Объявить переменные:
- **N** — целое число, введённое пользователем.
- **sum** — сумма всех слагаемых.
- **i** — счётчик цикла.

3. Ввести целое число N.

4. Проверить, что N больше или равно 1.

5. Если N меньше 1, вывести сообщение об ошибке.

6. Если N больше или равно 1, присвоить переменной sum значение 0.

7. При помощи цикла for выполнить сложение чисел от 1 до N.

Каждое следующее слагаемое вычисляется по формуле:

```c
sum = sum + 1.0 / i;
```

8. После завершения цикла вывести полученную сумму.

9. Конец.

## 2. Реализация программы

```c
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    int N;
    int i;
    double sum = 0;

    puts("Введите число N:");
    scanf_s("%d", &N);

    if (N >= 1)
    {
        for (i = 1; i <= N; i++)
        {
            sum = sum + 1.0 / i;
        }

        printf("Сумма равна: %.4f\n", sum);
    }
    else
    {
        puts("Число должно быть больше 0!");
    }

    return 0;
}
```
